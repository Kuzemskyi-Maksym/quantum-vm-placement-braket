# Квантове розміщення ВМ — порівняння методів (AWS Braket)

Код для порівняння 5 методів розв'язання задачі розміщення віртуальних машин (VM placement / consolidation),
сформульованої як QUBO/CQM, на спільній тестовій конфігурації. Продовження першої статті
(QAOA + SLR), тепер із запусками на реальному квантовому залізі через Amazon Braket.

Супровідні нотатки (контекст, рішення, журнал) — в Obsidian-сховищі, не тут.

## Спільна тестова конфігурація (`config.py`)
- 6 ВМ з навантаженням `[3, 4, 2, 5, 3, 4]`
- 3 ФС з місткістю `[12, 12, 12]`
- Порогова утилізація `T = 0.9`
- Множники штрафу `λ1 = λ2 = 6.0`

## Методи
| Файл | Метод | Інстанс |
|---|---|---|
| `mbfd.py` | MBFD (Modified Best Fit Decreasing) | повний |
| `cp_sat.py` | CP-SAT (Google OR-Tools, точний) | повний |
| `genetic.py` | Генетичний алгоритм | повний |
| `annealing.py` | SimulatedAnnealingSampler (`dwave-samplers`) | повний |
| `qaoa.py` | QAOA (Qiskit Aer) | зменшений (3 ВМ, 2 ФС) — див. нижче |

`cqm_model.py` — побудова CQM/BQM (dimod), використовується QAOA.
`run_all.py` — запускає всі методи, зберігає `results.json`.

### Чому QAOA на зменшеному інстансі
Повний інстанс (6 ВМ, 3 ФС, 21 CQM-змінна) після точної CQM→BQM конверсії (slack-біти для
нерівності місткості) розростається до ~33 кубітів — більше за місткість реальних гейтових
QPU (IQM Garnet ≈ 20 кубітів) і важко навіть для локальної statevector-симуляції. Тому QAOA
запускається на під-інстансі (перші 3 ВМ, 2 ФС → 16 кубітів) — цього достатньо для реального
прогону на IQM Garnet (`eu-north-1`). `qaoa_ising_params.json` містить готовий Ising-гамільтоніан
і оптимальні кути з локального прогону — для подальшого запуску на реальному QPU без повторної
оптимізації кутів.

## Встановлення
```bash
pip install dimod dwave-samplers ortools qiskit qiskit-aer scipy
```

## Запуск
```bash
python run_all.py          # усі методи одразу, результат у results.json
python mbfd.py              # окремий метод
python cp_sat.py
python genetic.py
python annealing.py
python qaoa.py
```

## Результати (останній прогін)
Див. `results.json`. Усі 4 класичні/гібридні методи на повному інстансі знаходять оптимум
(3 активних ФС, підтверджено CP-SAT). QAOA на зменшеному під-інстансі знаходить оптимум
(1 активний ФС).

## Наступні кроки

- Переформулювання через Maximum Independent Set для QuEra Aquila (апаратний аналог відпалу)
